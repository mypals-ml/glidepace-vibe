## Gap And Risk Review

- The project does not store historical status transitions, so historical burndown can only use the current Done status plus the task target date as the completion date.
- Today's actual point must match the same status-weighted remaining workload used by the projected line, otherwise the solid and projected lines can visibly jump.
- Open tasks whose target dates are in the past must remain in remaining work until their status changes to Done.
